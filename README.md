# 分镜台 Studio · v0.3.0

本地优先的视频制作台：把长文稿加工成可录音、可拍摄、可交接的生产资料。

[**在线体验**](https://compassscout.github.io/storyboard-studio/storyboard-studio-v3/) · [**下载 v0.3.0**](https://github.com/compassscout/storyboard-studio/releases/tag/v0.3.0) · [**桌面版 v0.3.0**](#桌面版-v030)

[![制作台总览](storyboard-studio-v3/screenshots/overview.png)](https://compassscout.github.io/storyboard-studio/storyboard-studio-v3/)

## 现在是什么

- **v0.3.0 桌面版**：Windows 安装包 / 便携版，下载后直接本地运行，不需要 Node、不需要联网。
- **v0.3.0 制作台原型**：静态 Web 预览，入口是 `storyboard-studio-v3/`，用于验证新的信息架构与交互。
- **v0.2.0**：历史版本，保留在仓库根目录。

桌面版目前沿用现有的 Electron 工作流；制作台原型尚未接入桌面端，两者不是同一个入口。

## v0.3.0 制作台

一条视频就是一个制作台：

- **左侧**：这一条视频的小节队列，可按状态和关键词筛选；
- **中间**：当前小节的「配音稿 → 分镜 → 素材与交付」三步流水线；
- **右侧**：检查器与固定的「下一步」主按钮。

小节状态不再手工勾选，而是由「正文是否定稿 / 分镜是否确认 / 素材缺口」自动推导：

- 改正文会回到「待定稿」；
- 改镜头会要求重新确认分镜；
- 采用校对建议会真的改正文，并且可撤销；
- 缺素材只提示，不阻塞交付。

交付包由前端真实生成 zip，包含：配音稿 `.txt`、分镜表 `.csv`、素材清单 `.csv`、字幕 `.srt`、项目数据 `.json`。

> 原型使用内存中的 mock 数据，刷新后恢复示例；不写入本地文件，也不调用后端或 AI。

### 下载与运行

| 文件 | 用途 |
|---|---|
| `storyboard-studio-0.3.0-setup-x64.exe` | Windows 10/11 x64 安装包，带安装向导和卸载项 |
| `storyboard-studio-0.3.0-portable-x64.exe` | Windows 便携版，双击直接运行 |
| `storyboard-studio-v0.3.0-web.zip` | 制作台原型网页包，解压后双击 `index.html` |
| `storyboard-studio-v0.3.0.zip` | 完整源码 |

也可以直接打开仓库里的 `storyboard-studio-v3/index.html`，或访问上面的在线地址。

### 推荐体验路径

1. 默认停在「黄金时代」，点击正文高亮，逐条采用或保留校对建议；
2. 点「完成配音稿」，进入分镜，修改一个镜头时长，看它要求重新确认；
3. 在素材页把「未找到」改成「已下载」，观察缺口数量变化；
4. 打开故事板预览翻镜、播放；
5. 打开交付包，勾选文件并生成 zip；
6. 新建项目，把一篇长文稿按标题拆成小节。

## 桌面版 v0.3.0

Windows 10/11 x64 用户下载上面的 `setup` 或 `portable` 后直接运行，不需要安装 Node，也不需要联网。

从源码运行：

```bash
npm install
npm start
```

也可以直接用 Chrome 打开根目录的 `index.html`。

### 桌面版功能

- 新建项目：项目名 + 原始文稿，支持粘贴和导入 `.txt` / `.md`；
- 项目保存在浏览器 `localStorage`，支持删除、重命名；
- 文稿处理：按标题拆分小节，「对照 / 原稿 / 修订」三种视图；
- 本地规则校订：连续空格、英文标点、重复字、重复标点；
- 安全项批量接受，需确认项逐条采用或保留；
- 按整节文案生成镜头，按句子长度估算时长；
- 本节播放器，默认 16:9 1080p，可切 720p / 4K / 9:16 / 4:5 / 1:1 / 21:9 / 4:3；
- 真实下载 CSV，可用 Excel 打开。
