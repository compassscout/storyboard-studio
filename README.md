# 分镜台 Studio · v0.2.0

一个**本地优先**的视频分镜与装配工作台原型。

按「项目 → 集 → 章 → 节 → 镜头」组织内容，先处理原始文稿，再生成镜头表，最后进入本节装配。

当前版本是可运行的功能原型，不是完整剪辑软件。

## 本地运行

直接用 Chrome 打开 `index.html`，或：

```bash
npm install
npm start
```

## v0.2.0 已实现

### 项目

- 新建项目：项目名 + 原始文稿；
- 支持粘贴、导入 `.txt` / `.md`；
- 项目保存在浏览器 `localStorage`；
- 删除项目、重命名项目。

### 文稿处理

- 按标题自动拆分小节；
- 「对照 / 原稿 / 修订」三种视图；
- 右侧修改清单：安全项 / 需确认；
- 接受安全项、逐条采用 / 保留；
- 本地规则检查：连续空格、英文标点、重复字、重复标点；
- 完成定稿后，才允许进入镜头表。

### 镜头表

- 按整节文案自动生成镜头；
- 按句子长度估算镜头时长；
- 按关键词给出画面类型。

### 装配

- 本节播放器 + 本节时间线；
- 16:9 1080p 默认，可切 720p / 4K / 9:16 / 4:5 / 1:1 / 21:9 / 4:3；
- 播放器容器随尺寸变化，不是只裁画面。

### 导出

- 真实下载当前项目 CSV，可用 Excel 打开；
- 其他导出格式仍是界面演示。

## 示例内容

仓库内置三篇约 5000 字的示例文章，用于测试长文拆分、文稿处理和镜头生成：

- 《从码头到枢纽：鹿特丹港如何重塑一座城市》
- 《从纸张到屏幕：信息载体如何改变知识传播》
- 《铁轨上的腹地：一条铁路如何改写芝加哥的命运》
